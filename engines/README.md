# OmniCut 内置内核

产品、Agent 和视频工程现在由同一个仓库交付。用户在根目录运行 `npm run setup -- --prepare-browser`，再用 `npm start` 启动；安装脚本不会克隆上游工程，也不依赖父目录里的项目。

| 目录 | 产品实际使用的内容 | 开发方式 |
| --- | --- | --- |
| `agent/source` | 固定版本的 Agent 内核源码、聊天前端、工具与构建链 | 修改源码后从根目录运行 `npm run agent:rebuild` |
| `agent/runtime` | 与源码同版本的运行包和聊天前端资源；通过本仓库的 npm workspaces 解析 | 编译产物随源码提交，用户安装不需要构建整套框架 |
| `video` | 语义视频工程、编辑器、渲染、组件、技能与服务源码 | 应用直接使用这里的源码，启动时构建编辑器 |

项目、素材和本地状态放在根目录 `data/`。配置仍由「模型设置」管理，内化不改变现有模型接口，也不迁移聊天数据格式。旧工程中的包名、对象身份、语义锚点继续保持兼容。

独立安装不意味着没有普通软件依赖：Node.js、FFmpeg、npm 库、渲染浏览器和用户选择的模型 API 仍然需要。它意味着用户不再安装、配置或管理另外两个产品。

本仓库保留底层包名与来源信息，不把内化等同于从零自研。来源及许可见 [视频内核说明](video/UPSTREAM.md)、[Agent 内核说明](agent/README.md) 和 [第三方归属](../THIRD_PARTY_NOTICES.md)。
