# 广告创意与制作协作

## 简报：给目标，不替导演写答案
读取项目与用户原话，按下列条目形成短简报。已有答案直接复用，不把表格变成用户必填问卷。
- 用户原始目标：品牌形象、商品种草、效果投放或解释演示；不要把投流降格为泛情绪片。
- 受众与场景、希望观众采取的行动、时长画幅。
- 已核实事实：每条事实附用户输入或商品页面/素材来源；未知项明确保留，不把模型印象当事实。
- 商品身份：真实品牌/虚构概念，现有参考素材文件、外观特征与来源。真实商品不能凭空设计包装；虚构概念才允许原创设计。
- 硬约束：用户明确指定的模型、预算、禁用事项与必须保留的创意。
- 可调整建议：用户说“参考/例如/可优化”的故事、主角、场景，不升级成必须执行的规则。
- 实际能力与风险：现有素材、服务可生成的时长范围；生成素材时长与最终剪辑时长分开。不要把模型最短时长变成固定镜头长度，更不要自己规定必须是五个生活镜头。

商品资料不足时先查现有素材和明确商品来源；没有真实包装图不能悄悄生成近似包装。只有缺失事实会改变商品身份/核心诉求才问一个具体问题；缺少价格或促销就不写促销，不因此禁止所有产品体验表达。

## 委派与验收
有 creative_director 就先委派上述简报。导演已直接注入本技能的创意方法参考，无须发送整份技能、历史对话或源码。原生子代理入口只接收文字，不直接读取或观看媒体，也没有联网、生成与工程权限；主 Agent 提供可靠商品事实、参考分析结果及实际抽帧/转录证据。analyze_reference 与 analyze_video 已由同一创意模型处理真实画面序列，不能用主 Agent 凭空概括替代。
导演返回：一句创意主张、前两秒可见动作、商品在故事中的作用、关键记忆画面、旁白、连续分镜、声音和收尾行动。主 Agent 对照以下问题检查，并具体指出不足；初稿、关键参考画面和初剪分别按需要交给导演打磨；每轮最多6次，允许有实质目的的多次修订，不以省调用为由跳过质量判断，也不为凑次数重复委派。
1. 只看前两秒，观众看到什么变化？“高级、轻快、有感染力”不算动作。
2. 去掉商品或换成任意品牌，故事是否几乎不变？若是，补商品行为/形态/体验与记忆画面的因果关系。
3. 这是用户要的广告吗？效果投放需要清楚使用理由与行动承接，不用虚构优惠；品牌片可以留白，不强塞购买口号。
4. 有无真实可展示的体验/证据？“清新口味/包装形态/无糖”等需来源，情绪比喻不能伪装成功效。
5. 静音时能否认出商品、理解关键表达？字幕不是把全部旁白塞满屏。
6. 用户目标情绪是否落实到画面与声音？例如“明快、有食欲”应在光线、动作、镜头长短和音乐上可观察，不能用安静加班故事替代后仍自称符合。
7. 分镜是否可执行且有节奏差异？长短镜头服务注意力，不把慢镜头、淡入淡出等同于高级。

不要用自打高分代替判断，给一两条可观察的理由；禁止要求导演的检查结果“必须为无问题”，允许真实不足浮现。模型最短生成4秒不意味着剪辑分镜必须3–8秒，允许短促插剪与长镜交替。用户要求直接制作时自行选择合适方案继续，不新增确认关卡。只要求先看方案则停在方案。
生成商品/人物参考后，检查每个动作的初态与末态：未开封→开封、倒水前→倒水后、手持姿势和商品朝向；冷饮不能靠持续热蒸汽表达冰爽。参考图好看不代表适合接下来的动作。

创意落定后 set_production_plan 保存中文镜头表；随后读取 frame-commercial-video，执行生成、声音、剪辑与导出。纯字幕位置、音量或取段参数调整由主 Agent 直接执行；若暴露叙事、商品关联或情绪节奏的问题，可再次委派导演提出具体修改。

## 基于证据的导演评审
新片关键画面或初剪出现后，先通过 analyze_video 或主 Agent 实际读取帧获得有来源的视觉观察，再把时间点、观察、语音转录和当前方案交给导演，请它指出具体可修的问题。不能只发送原生成提示词就称已评审。参考理解使用真实抽帧与本地语音识别；未直接听取音轨，不判断口音、音色、音乐或混音。导演应区分已观察、推测与新设计；工程主 Agent 决定可通过取段、重排、动效、字幕或音轨解决的改法，然后落地，不把评审长文当交付。
