# 广告创意与制作协作

目标：找到符合用户目标且可执行的广告表达。产出：短简报、结构化 proposal 或基于证据的 review。完成标准：事实有来源，创意与商品/品牌关联明确，逐镜路线可实施，主 Agent 已核对并保存方案或落实修复。

## 形成短简报
读取用户最新意图与项目上下文，复用已确认信息：目标与受众/场景、希望观众采取的行动、时长画幅、真实商品或虚构概念、事实与素材来源、用户硬约束、可调整建议、可用能力。品牌形象、效果投放和解释演示采用相应表达；“参考/例如”保持为建议，预算未设不阻塞制作。

商品事实先查现有资料和真实参考。未知功效、价格、认证不写成主张；事实不足仍可用已知形态、使用场景和视觉设计创作。每镜选择 generated/code/hybrid，生成素材时长与剪辑时长分开。

纯代码、字排、界面或风格提升需要参考实现时，主 Agent 可先用 list_motion_components 找完整场景与基础动作，get_motion_component 看实际用途与源段落，将合适候选的设计关系和可用区间纳入导演简报。目录描述是实施线索，未看实际画面就不称已审过；方案不受库片长或模板结构绑定，也不强制每片用动效。

方向未定的新片或参考改编，首次生成素材前默认用原生 ask_user_question 问一两个具体表达选择，例如先展示用途还是先建立品牌气质，每题给少量可比较选项与推荐理由。用户已说“你定/直接做”、已有采用方案、已确定方向或纯局部剪辑时跳过；已回答的选择直接复用，不追加生成权限或预算确认。只看方案时停在方案；待答时先保留方案，超时不是同意。示例见 frame-commercial-video 的 references/examples.md。

## 委派与交接
creative_director 的文字简报首行写 `mode: proposal`；真实评审首行写 `mode: review`。模式决定原生结构输出，详见 [director-method.md](references/director-method.md)。新广告、参考改编或产品介绍先委派 proposal，已有采用方案直接复用；有效修订与关键画面/初剪评审按实际需要再用，次数与简报限制由工具声明和系统提示控制，不为凑次数重复调用。不可用时由主 Agent 完成创作。

只发送短简报和有来源的观察/转录，保留 evidenceMode、时间点与不确定项。导演不直接读取媒体，没有联网、生成、工程或继续委派权限；不能把它的文字建议当作已观看结果。proposal 返回 {kind:"proposal",proposal,productionPlanInput}，主 Agent 核对时间、route、事实与当前能力后，将 productionPlanInput 直接用于 set_production_plan（scenes 与 creative 已是 JSON 字符串），再加载 frame-commercial-video 实施。review 返回 {kind:"review",review}，用于局部修复，不直接覆盖制作方案。

## 验收表达
1. 前两秒有哪些可见变化或清楚的信息？形容词落实为动作、构图或节奏。
2. 商品/品牌怎样推动画面或记忆点？换成任意品牌仍成立时补具体关联。
3. 表达是否服务投放目标和行动承接？品牌片可留白，效果片的使用理由有依据。
4. 体验、事实与功效是否有来源？视觉比喻与产品事实清楚区分。
5. 静音时能否识别商品和关键表达？文字密度与实际可读性合适。
6. 用户目标情绪能否在光线、速度、音乐和旁白中观察？
7. 镜头路线是否可执行，长短与衔接是否服务注意力？

初稿用一两条具体理由判断；真实 review 提供 keep 和按影响排序的 issues，保持诚实不足，不要求自评分或“无问题”。先取得实际帧、视频分析或转录证据再委派 review；frames-transcript 不能判断未听取的音色/音乐/混音。主 Agent 选择取段、重排、文字、组件或音轨的最小修复并落地，不把评审长文当交付。
