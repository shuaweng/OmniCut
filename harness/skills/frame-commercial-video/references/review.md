# 预览、判断与交付

目标：依据实际画面和声音作制作决策。产出：代表帧/小样证据、必要修复及可播放成片。完成标准：高影响问题已处理或明确披露，技术结果与创意判断分开，保留可编辑工程。

## 先检查局部，再完整导出
1. commit 后 preview_frames 读取真实代表帧和切点；运动需要时用可用的不超过3秒 sample。工程小样静音，只验证画面；代表帧仅证明对应时刻。核对文字字心/对比、主体遮挡、商品身份与比例、动作初末状态、切点和结尾。
2. 信息卡、字幕和产品保持全程安全区。字体与绘制层按 hypit-editing.md；亮底优先调整位置、对比或克制底衬，先底衬/描边后白字。字幕样式改变不改语音时钟。
3. 将“时间段、实际观察、证据类型、最小修复”记入 production-notes.md，明确已观察、推测和新设计。理解服务使用本轮 videoUnderstandingConfiguration，以结果 evidenceMode 为准：video-audio 有真实视频/音轨，frames-transcript 只有抽样帧与转录。
4. 先取段、裁切、移动文字、调整独立音轨或替换已有镜头；确实无法修复才重生成该镜。用户已授权制作时自行完成常规局部修正，验证该处及衔接；有新问题才扩大检查，合格后推进交付。
5. export_video 的 summary 写本版实际修改，提交后 await_tasks 等待 export:ID。done 后 probe_export(jobId) 核对真实时长、画幅、音轨、响度及疑似黑帧/静帧区间；检测区间是线索，需结合创意和对应画面判断。

需要读取实际文件时 stage_export(jobId)，使用返回 file，抽查开场、切点、字幕、商品和结尾。音轨数量不能证明混音内容，未试听不称自然；技术通过也不等于商业表达已通过。只为一个局部检查时用局部预览，不反复完整重导。

## 记录与呈现
制作日志保留素材 ID、可用/坏帧区间、连续性、证据文件和采用决定，后续复用判断。人物记录外观、服装、持物与左右关系；商品记录形态、结构和标签来源。尾板合成真实商品图时检查底色、去底边界与字标，不把生成乱码称为稳定品牌。

诊断抽帧、拼图、中间音轨留在 analysis/；publish_workspace_asset 只发布进入成片或需要用户选择的媒体。中文展示名用“{项目名}·广告成片”等当前任务信息。

最终通过 export_video / stage_export 的真实产物卡交付，简短说明成片、关键修改及未核实项；使用实际返回结果，不猜链接、不贴内部日志或自评分。保留源码、Author Package、Companion 与独立音轨供继续编辑。
