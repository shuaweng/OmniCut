# 制作表达示例

以下是表达格式，素材身份与事实须换成当前项目的真实值；示例本身不是已完成的工程或用户约束。

## 15秒竖版混合广告
背景：用户提供真实产品视频和“收纳更顺手”的已确认体验，希望轻快、清楚说明用途。

| 场景 id / 时间 | route | 画面意图与素材身份 | 旁白对应 |
| --- | --- | --- | --- |
| opening / 0–2s | code | 原生文字揭示“桌面，清爽一点”；颜色与位置为公开参数 | 留白 |
| action / 2–7s | generated | 使用素材表中的真实操作视频，取已检查的整理动作区间 | “常用物件，放到顺手的位置。” |
| detail / 7–11s | hybrid | 真实产品特写叠加可编辑位置提示，按该句 selection 出现 | “拿取和归位，都更清楚。” |
| ending / 11–15s | hybrid | 用户真实产品图与品牌字标，保持连续音乐并留收尾 | 用户已确认品牌句，或留白 |

set_production_plan 使用各行 id/name/start/end/visual/voiceover/route；真实声音生成后按证据调整时间。旁白句子在这里仅作格式示意，不能据此新增产品功效。

## 方向未定的新片：首次素材前的具体选择
用户要求制作新片或参考改编但尚未确定表达方向时，首次生成素材前默认用实际原生 ask_user_question 参数给具体选择：
```json
{"questions":[{"id":"opening","header":"开场方向","question":"这条片更需要先展示产品用途，还是先建立品牌气质？","options":[{"label":"先看用途 (Recommended)","description":"用真实操作建立使用理由，适合当前讲解目标。"},{"label":"先看品牌气质","description":"用代码文字与节奏开场，产品操作随后出现。"}]}]}
```
用户已说“你定/直接做”、已有采用方案、方向已明确或纯局部剪辑时自行执行；方案阶段已回答就复用选择，不重复权限或预算确认。待答时保留方案，等待超时不等于用户选择。

## 简短进度
- 方案已保存，接下来把现有操作视频和文字镜头接入同一工程。
- 初剪已能预览，正在修正尾板文字与产品图的间距。
- 配音任务暂停查询，已有画面已保留；恢复结果后继续字幕和混音。

## 审片记录

| --- | --- | --- | --- |
