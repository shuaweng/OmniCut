# 从镜头意图到动效时间线

用于新动效、风格提升或参考改编。保留已有创意决定，补足能直接实施的动作与时间关系；不为每个局部改稿重新写一套方案。

## 动作表达信息

| 镜头要表达的关系 | 可选择的动作 | 决定成败的画面 |
| --- | --- | --- |
| 先建立一个重点 | 掩膜显字、线条引导、光扫、局部放大 | 核心词先于次要信息落稳，完整可读 |
| 两件事比较 | 分屏、平行显现、对齐、差值连接 | 同一尺度和共同基线，差异有事实依据 |
| 原因推动结果 | 路径生长、连线、由源头扩展、按距离重排 | 起因可见，结果发生后关系仍清楚 |
| 产品或界面层级 | 分层视差、窗口扩展、细节卡片、跟踪标注 | 运动不遮住商品，标注始终跟随目标 |
| 多个步骤或数量 | 网格收拢、序列错峰、图表揭示 | 数字准确，先看整体再看重点 |
| 完成与行动承接 | 归位、收束、尾板、停留 | 最后状态稳，品牌或行动信息有阅读时间 |

由当前库提供的实际组件选实现；名称、用途相近时比较一次最有意义的差别，例如紧凑排版与空间展开。无适配组件时，先说明欠缺的行为再小步扩展已有包。人物、真实产品操作和环境运动仍由当前可用素材或生成能力承担。

## 风格规则与样片分开

记录本镜需要保持的规则：字体角色、色彩关系、元素密度、曲线性格、空间层级和转场方式。精确排版可用克制的收拢和掩膜；柔软材质可用延迟与缓动；技术信息强调尺度和清晰关系。不要把每个风格统一成弹簧进场。

先用当前主题确定动作和结束状态，再参考样片的实现。只换 Demo 文案会沿用 Demo 的结构、节奏和商品角色；应保留适合当前主题的风格规则，重新编排内容。局部采用某个效果无需重做整条片子的风格。

## Cue 时间表

以当前 Timeline / 帧率和真实语音或音乐时序为依据，把有必要对齐的时刻写成短表，可保存在现有制作计划或 production-notes.md。音轨的源时间与影片时间不同，使用已映射的锚点，不猜源偏移。

| Cue | 时间或锚点 | 可观察的变化 |
| --- | --- | --- |
| 准备 | 当前镜头开始 | 起因、目标区域或前景已经可见 |
| 揭示 | 当前语义重点或已确认音乐落点 | 主元素到位；动作提前起步，使落点对应完成状态 |
| 阅读 | 主信息完整显示之后 | 摄影和装饰运动让出注意力，核心信息稳定 |
| 承接 | 当前镜头退出之前 | 元素把视线交给下一镜或缩回对应来源 |

时长不是平均分摊：进入与退出服务动作，停留服务阅读。中文信息卡可用字数 / 4.5 + 1.5 秒作为初始估算，再按字号、难度、已有旁白和画面调整；这不是字幕统一时长或硬门槛。动画中的打字、滚动和未完全显现阶段不算完整阅读时间。时段太短时先减文字或拆信息，避免把全部内容加速一遍。

音乐、图形与音效共用已确认的 cue；静音广告仍应看懂核心表达。连续片段保留快慢变化和必要停留，不设置固定镜头运动数量或静默配额。字幕按真实语音 alignment 编排，不能为装饰性卡点移动关键台词。

## 验收当前镜头

代表帧确认主体、字心、对比、信息落稳和退出状态；短样确认触发、跟随、运动连续性和切点。场景摘要和编译成功不等于已看过效果。抽帧只证明对应时刻，静音小样不证明音效、配乐或混音。把有影响的问题写成“时间点、实际观察、最小修复”，保留合格部分。
