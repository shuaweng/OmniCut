# 完整场景的源码复用与片段改编

用于采用完整设计场景的一段、替换其内容或延续其设计。局部文字叠层不必加载本篇。先沿已选包的真实 README；不同包的输入、字体和输出不能互相猜用。

## 看懂原设计，再落当前内容

`get_motion_component` 不改工程，返回 README 与源文件名；`use_motion_component` 才把包复制到本视频草稿，并返回 `workspaceDirectory / absoluteDirectory / sourcePaths / revision`。返回的 starter 已提供实际 Film、字体和源窗口接线，先用公开参数提交首版。仅需改未公开内容或摄影行为时才用原生 `read` 读取这些真实路径：入口说明输入，渲染适配器说明 clock 与字体，原始 film、样式和时间数据说明具体构图、动作及镜头关系。只读当前改编相关文件；修改某个现有文件前实际读取它，历史聊天摘要不能代替本轮文件读取。

参考价值来自原场景的整套设计：字体角色、基线与留白、主次比例、运动曲线、摄影/空间变化、元素间延迟与共同时间。保留这些关系，通过内容和片段编排服务当前主题。不要看到原片后重新用通用卡片、统一 cubic/smooth 或品牌揭幕拼一个近似版；也不把原片全部缩到目标时长。新内容需要的行为超出原设计时，才在保留原实现的项目副本上扩展。

优先改公开参数。未公开的文案可能存在原始 `lines.json`、场景模块或数据表，读取后按角色改写，并核对实际画面；不要机械全局替换字符串。保留数组与场景索引、节奏关系，确需删场景或延长阅读才改关联 cue。旧样片的事实、旁白或品牌不自动成为当前任务内容。

## 原字体是输入

`nativeFonts` 列出随包保留的原字体文件与角色；README 声明相应 Surface 的 typed font 输入。引用包内真实 `fonts/…`，由消费工程声明 `asset:Font` 并传入指定输入。路径相对当前 SVML 文件，使用 `absoluteDirectory` 定位文件，不能猜另一个包的字体名或只读 fonts.css 就称字体已接入。按 README 填写 weight/style；metadata 中变量字体的 `100 900` 是字体轴范围，不是 `asset:Font` 的整数 weight。中文 fallback `font` 与原拉丁字重/衬线/等宽角色并存，不把原字体全部换成 FrameSans-Regular。

保留随包的许可、来源记录和字体文件。HTML/CSS 内的远程字体或文件路径不是 native 字体接线；本包的渲染适配器与 README 提供实际接法。

## 源时间与影片时间分开

`segments` 的 start/end 属于原场景秒数，`sourceDuration` 是完整原场景片长。调用的 start/end 是当前 Timeline 上的可见窗口。把组件移动到片中或裁短时间窗，并不自动选中原片中段。

当包真实公开 `sourceStart` 和 `rate` 时，按 README 使用它们：`sourceStart` 为源起点秒数，`rate` 为源播放速率，共同映射所有场景元素到原时钟。概念关系是：

```text
源秒数 = sourceStart + (影片秒数 - 本镜 start) × rate
目标时长 = (源 end - 源 start) ÷ rate
```

例如采用源 12–17 秒并保持原速，目标窗口可放 8–13 秒，`sourceStart=12`、`rate=1`。实际源段与参数范围来自已选包，不照抄示例。若没有公开源起点或速率，不发明属性；读现有 native clock 适配器后小步加入源时间映射，或采用包已支持的段落接口。只改 Timeline 窗口不等于完成源裁取。

先按本片叙事选择有意义的源段，检查该段第一帧的起始状态、信息落稳和末帧交接。跨源切点的段落可以保留原过渡；切到动作中间则依当前表达调整选段，不能让裁取造成意外黑场或半句。长中文需要留阅读时间或减少文案，不把全场景加速后当成适配。普通字幕与配音仍沿当前任务真实时序，原片示例音轨只有本任务需要且来源适用时才接入。

## 保持原实现可改、可 seek

在同一 Film 引用实际 `.track`，共用当前 Canvas / Timeline，保留现有素材、字幕和音轨。完整不透明场景适合作为自己的镜头；仅声明并实现透明的组件可当叠层。`use` 后沿当前草稿读写，不再 checkout 覆盖。

修改行为时保留原 HTML/CSS/Canvas/SVG、数据与 easing；在适配边界转换时间与资源，不把整套设计重建为简化 sceneKit。`browserProgram` 的逐帧求值仍以 native frame 为权威，公共时钟同步摄影、物体、文字、光效；墙钟播放、累积粒子和未经 seek 的外部时间线会破坏任意帧预览。对原代码中 GSAP/WAAPI 等自主播放，需暂停并按源时间 seek；依赖与媒体沿现有包及 typed Artifact 接线，不从远端运行时下载。

读渲染入口确认它直接引用源文件还是生成的 `bundle.js / scene.js`。改了原场景源码或数据但运行入口使用 bundle 时，优先按 use 返回的 `localBuild.arguments` 调用 `rebuild_motion_component`，成功后再 commit/preview；它运行包声明的 `buildScript`，复用本地已有依赖，不需到终端寻找引擎路径。只改公开调用参数不需重建。没有声明此入口时才沿 README 在真实包目录运行已有本地 build 脚本。只改 `source/` 而没有重建 bundle，预览仍是旧画面；保留原始源码与可重建产物，不手工只改 bundle，也不运行上游安装、配音或音乐生成脚本。

调用方保存本片内容与选段。局部实现可以继续在当前 `packages/` 改；新增用户可调项时同步 Surface、config、binding、Inspector。需要跨项目保存改编版，commit 后更新包版本及 README，再 `save_motion_component`；不用原库版本名暗覆盖已有设计。

## 当前改编的最小验收

commit 已完成编译后，`preview_frames` 看目标片段的入点、动作中、阅读状态和出点；改了动作或源时间再看不超过 3 秒的小样。检查中文字形、原字体角色、画幅适配、构图、源切点和相邻镜头。原预览的横屏设计不能证明竖屏排版已经适配。编译通过、基础组件可运行与当前商业效果合格是不同判断，结论依据实际画面。

修复本次改编的问题后继续 export / await / probe 与实际审片，不为一个片段完整重渲染原样片或重复验证无关组件。
