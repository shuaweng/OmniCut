# 代码镜头语言

目标：代码画面不再是“元素在平面上滑动”，而是有一台被设计过的摄影机。产出：每镜的相机路径表、分层深度设定与真实预览帧。

## 一台相机，一个世界

- 所有元素放在同一个世界坐标里，相机只有一组参数：位置（x, y）、推进量 z、旋转角、缩放与焦点深度。画面里的每一层由相机参数换算出屏幕位置，而不是给每个元素单独写屏幕坐标。
- 每一帧只由时间决定：任意一帧单独渲染、乱序渲染都得到同一画面。不读取墙钟、不用未固定种子的随机数。
- 跟随主体的效果（聚光、圆形遮罩、标注线）也从世界坐标换算，运镜之后仍然贴住主体。

## 运镜词汇与写法

- 推 / 拉：z 随时间变化，画面缩放约为 1 / (1 − z)；推近时远景层几乎不动、近景层放大更快。
- 摇 / 俯仰：围绕相机中心旋转，整个世界一起转；幅度一般不超过 8°，否则改用移镜。
- 移 / 跟：相机 x 平移，各层按深度乘以不同系数移动——远景 0.2、中景 0.6、前景 1.0、贴脸前景 1.4。
- 升降：相机 y 变化并伴随轻微俯仰，制造揭示感。
- 变焦冲击：短时间内缩放 1 → 1.08 再回落，配合重音，一片最多用两次。
- 焦点转移：焦点所在层清晰，其余层按与焦平面的距离加模糊与降低对比度。

## 缓动

- 起势与收势要有加速与减速：常用三次缓出做进场，平滑阶梯（3x² − 2x³）做来回运动；镜头停下前留 6–10 帧的减速。
- 预备、动作、跟随：重要运动先反向轻移 3–5%，再完成主运动，最后小幅过冲回弹。
- 每镜一个主运动，次要运动幅度不超过主运动的三分之一。

## 分层

至少三层：背景（色场、纹理、远景）、主体（产品、人物、界面）、前景（光斑、颗粒、模糊遮挡）。前景层让推移产生深度，比多加元素更有效。

## 落地

1. 在 motion-direction 选好组件或场景后，按本技能写相机路径表：时间、运镜类型、起止参数、缓动、对应的信息点。
2. 用 video-workspace 把相机参数做成包内的统一函数，通过公开参数暴露幅度与速度。
3. preview_frames 抽查起点、中点、终点与转场前后各一帧，确认主体始终占画面高度三分之一以上、没有空帧。

## 标志镜头

每条片子设计一个标志镜头：一次长时间推进穿过多层界面、一次尺度揭示（从细节拉到全景）、或一次在介质内部完成的转场（纸页翻起、墨迹扩散、界面折叠）。
