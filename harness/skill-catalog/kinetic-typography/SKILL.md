# 动态字排

目标：文字既好看又一定读得完。产出：字排节拍表与可编辑的字排镜头。

## 设计步骤

1. 拆句：把文案拆成 1–3 个意群，每个意群一个画面；找出每句唯一的关键词。
2. 层级：关键词最大（画面高度的 15–25%），辅助词为其 35–50%，说明文字更小且降低不透明度。
3. 运动对应语义：
   - 冲击、速度：从画外快速推入，轻微运动模糊感，落位过冲回弹。
   - 稳定、信任：自下而上缓慢升起并淡入，落位后不再晃动。
   - 变化、转折：字形错位、遮罩切换或上下翻牌。
   - 列举：逐项错层进场，间隔 3–5 帧。
4. 节拍：重音落在关键词出现的那一帧；用 analyze_beats 的结果对齐切点。

## 可读性规则

- 停留时长不少于“字数 ÷ 4.5 + 1.5 秒”，口号类至少 2 秒完整静止。
- 同一时刻只有一个视觉焦点，避免两行同时运动。
- 文字与背景对比度足够；叠在画面上时加柔和压暗或色块底。
- 中文避免逐笔画拆散显示；逐字出现时整字出现。

## 组件

list_motion_components 用 query 搜「字排」「逐字」「轮廓」「字带」等，优先选与语义匹配的组件改公开参数；需要多句连续时，把几个组件放在同一时间线上首尾相接，而不是一个组件塞满全部文案。
