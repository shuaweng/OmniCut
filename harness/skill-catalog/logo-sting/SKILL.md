# 品牌标志演绎

目标：短、准、可重复使用的品牌出场。产出：演绎方案、可编辑的标志镜头与配套声音。

## 选择演绎方式

- 汇聚：碎片或粒子从四周汇聚成标志，适合科技与能量感。
- 描边：沿标志轮廓画线后填色，适合精致、手作或建筑感品牌。
- 遮罩揭示：色块或形状扫过，标志从后面露出，适合简洁现代的品牌。
- 光扫：标志定格后一道高光扫过表面，适合金属、玻璃与高端品牌。
- 拆分重组：字母或部件错位后归位，适合年轻、活泼的品牌。

## 规则

- 标志的形状、颜色、比例必须与用户提供的正式标志一致；需要正式标志文件时先确认来源。
- 动作在前 60% 的时长内完成，剩余时间完整静止定格。
- 背景干净，品牌色作为点缀；标志周围留足安全空间。
- 声音标识与定格那一帧对齐：一个短促的重音或上扬音型，时长 1–2 秒。

## 组件

list_motion_components 用 query 搜「揭幕」「遮罩」「粒子」「轮廓」；正式标志通过图片版本组件的图片输入接入，标志文字用字体资源，不用生成模型重画标志。
