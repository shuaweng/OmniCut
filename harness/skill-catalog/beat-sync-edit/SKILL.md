# 卡点剪辑

目标：每一次切换都“踩在点上”，同时保留镜头能被看懂的时长。产出：节拍图、切点表与卡点后的工程。

## 流程

1. 读音乐：配乐已在时间线上时用 analyze_beats，得到拍点、强拍与段落；需要新配乐时先 generate_audio 再分析。
2. 绑定参考线：bind_beat_guides 把节拍参考线绑定到工程，list_beat_guides 读取可用拍点。
3. 写切点表：段落 → 每个镜头的入点拍、出点拍、镜头内重音动作所在的拍。
4. 剪辑：用 adjust_hypit_timing 或 edit_timeline 把镜头时间窗对齐拍点；镜头内重音（开盖、转身、文字落位）对齐强拍。

## 节奏规则

- 强拍换镜，弱拍做镜头内运动；不要每一拍都切。
- 镜头最短约 0.6 秒（快剪段落），信息镜头至少 1.5 秒。
- 段落变化（进入副歌、鼓点加入）时改变剪辑密度或画面尺度，给观众“升级”的感觉。
- 结尾落在最后一个重音上，之后留 0.5–1 秒余韵。

## 自查

导出后整片听看一遍：是否有镜头切在拍点之间的“半拍”上、字幕是否跟着拍点出现、音乐结尾是否被截断。
