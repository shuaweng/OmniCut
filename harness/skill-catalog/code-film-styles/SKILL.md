# 代码短片风格库

目标：在动手写画面前先选定一种风格，并让全片遵守它。产出：风格卡（色板、字体、材质、运动节奏、转场方式）与按风格调整后的组件参数。

## 使用方法

1. 从下表选一种主风格，必要时只加一种辅助风格；说明为什么适合这条片子的内容。
2. 写风格卡：三到五个色值、标题与正文字体、纹理来源、运动节奏（每秒几次变化）、转场在介质内如何发生。
3. 选动效组件时用风格卡改公开参数（背景、文字、点缀色、速度、幅度）；组件不符合风格时只改包内对应的绘制段落。

## 风格速查

- 瑞士平面：网格、无衬线大字、红黑白；运动是沿网格的直线滑入与精确对齐，转场用色块整版切换。
- 暗色发布会：深灰底、单一品牌光、细线与玻璃卡片；慢推镜头，数字与图表逐项点亮。
- 丝网印刷：两到三种专色、错版偏移、颗粒；每秒 12 次变化，颜色层分别进场。
- 半调档案：网点、报纸纸色、打字机字体；放大镜头揭示网点，标注线逐条画出。
- 蓝图：深蓝底、白色细线、尺寸标注；线条按路径绘制，部件分解后再装配。
- 水墨：宣纸白、浓淡墨、留白；墨迹扩散做转场，镜头缓慢平移如手卷展开。
- 红色剪纸：中国红、镂空纹样、灯箱背光；纸层从两侧翻入，光从背后渐亮。
- 浮世绘：平涂色块、轮廓线、波纹纹样；横向卷轴式移镜。
- 全息界面：青色辉光、扫描线、环形读数；元素以闪烁两次后稳定的方式出现。
- 终端字符：等宽字体、绿色或琥珀色、光标闪烁；逐字打出，整屏滚动转场。
- 等距信息图：30° 等距网格、柔和配色；元素从下方升起，相机沿等距轴平移。
- 像素角色：限定调色板、整数像素位移；每秒 8–12 次动作，镜头整像素移动。
- 玻璃产品渲染：深色背景、边缘高光、焦散；慢速环绕与高光扫过。
- 纸艺立体书：卡纸层次、投影；页面打开时元素弹起。
- 移轴微缩：上下大面积模糊、高饱和；俯视慢移，物体像玩具一样小步移动。
- 默片：黑白、颗粒、暗角、字卡；每秒 16–18 次变化，用圈入圈出转场。

## 规则

- 整片只用一种主风格；风格之间切换必须有叙事理由。
- 质感（颗粒、纸纹、扫描线）要轻：不影响文字可读性，矢量风格可以完全不加。
- 风格名称只用于描述方向，不复制任何具体作品的画面、角色或标识。
