# 数据故事动效

目标：观众记住一个数字和它的意义。产出：数据结论句、图表选择理由与图表镜头。

## 三步揭示

1. 背景：坐标、分类或起点先出现，给观众参照。
2. 变化：数据按时间或类别依次生长，关键一项最后出现或用点缀色突出。
3. 结论：数字放大停留，配一句结论文案。

## 选图

- 比较多个类别 → 柱形生长。
- 随时间变化 → 曲线进度。
- 部分与整体 → 环形占比。
- 一个惊人的数字 → 数字跃升。
- 步骤、因果、流向 → 流程连接。

## 规则

- 数据只来自用户或已核实的资料；没有来源的数字不上画面。
- 一张图最多 6 个数据点；标签简短，单位写清楚。
- 数字跃升要停在准确值，结束后至少停留 1.5 秒。
- 颜色：普通数据用中性色，关键数据用品牌点缀色，全片一致。

## 组件

list_motion_components 用 query 搜「图表」「数字」「占比」「流程」；数据值和标签通过公开参数用逗号分隔填写，不改包代码。
