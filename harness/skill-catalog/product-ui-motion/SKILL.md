# 产品界面演示

目标：观众在几秒内看懂“操作一下就得到结果”。产出：操作链脚本、界面镜头与焦点标注。

## 操作链

每个演示镜头只讲一个操作链：起始状态 → 一次操作（点击、输入、拖入）→ 系统反馈（加载、生成）→ 结果出现 → 镜头停在结果上。写成表格：时间、光标位置、界面变化、镜头动作、旁白要点。

## 视觉规则

- 真实界面优先：用户提供的截图作为图片素材，用支持图片的组件（手机界面、切片揭示、产品聚光等的图片版本）放入；不要把示意界面当成真实产品截图。
- 代码重建界面时只保留讲解需要的元素：一个输入框、一个按钮、一张结果卡，去掉无关菜单。
- 光标与点击：光标匀速移动后在目标处停 4–6 帧，点击时按钮轻微缩小再回弹，并出现一圈扩散。
- 输入：逐字打出，速度约每秒 12–18 个字，结尾光标闪烁两次。
- 焦点：结果出现时镜头推近 10–20%，周围区域压暗或模糊，用细线标注关键数值。

## 节奏

单个操作链 3–6 秒；连续多个操作链之间用界面内的转场（卡片展开、页面滑入）衔接，避免硬切。

## 组件

list_motion_components 用 query 搜「界面」「手机」「卡片」「聚光」，kind 为 scene 的完整场景可截取其中一段操作。改动只改公开参数和图片输入，必要时再改包内绘制段落。
