# 动效创作简报

目标：开放需求先变成清楚的简报，再开始制作。产出：一页简报与分段时间表。

## 简报必填

1. 时长与画幅：例如 15 秒、16:9、30 帧每秒。
2. 一句话意图：观众最后要记住什么。
3. 风格锚点：一到两个具体的风格方向（例如“暗色发布会 + 玻璃卡片”），写色板与字体，不只写“高级”“炫酷”。
4. 运动词汇：从以下挑三到五个作为本片的动作语言——推入、错层、遮罩、描边、汇聚、爆散、翻牌、环绕、视差、弹性回弹、扫光、逐字。
5. 能量曲线：开场强度、中段如何变化、在哪里达到峰值、结尾如何收束。
6. 声音：配乐速度与情绪、几个关键音效与对应的画面瞬间。

## 分段时间表

按每 2–4 秒一段写：时间、画面内容、主运动、文字、转场到下一段的方式。相邻两段的主运动不要相同。

## 交给制作

- 代码动效：按时间表在 list_motion_components 里为每段选组件或场景片段，再按 motion-direction 落地。
- 生成镜头：把对应段落的画面与运动描述转写为视频提示词。
- 简报确定后写入 set_production_plan，制作中如有改动同步更新。
