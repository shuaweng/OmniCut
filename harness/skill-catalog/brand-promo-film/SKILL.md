# 品牌宣传片

目标：让观众记住一句品牌主张和一个画面。产出：创意主张、结构化分镜、可编辑工程与成片。

## 创意

先用 get_project_context 读取品牌事实、素材与既有方案，再写一句话主张。选择一种结构并说明理由：
- 单程旅程：主体从困境走到被品牌改变的一刻。
- 前后对照：同一场景在使用前后的差别。
- 倒计时：围绕一个即将到来的时刻逐步升温。
- 清单揭示：三到五个具体瞬间，最后一个揭示主张。

每条片子都要有“一个主体、一个目标、一次转折”；结尾要么呼应开场画面，要么揭示更大的尺度。前 3 秒必须出现主体或品牌关联。

## 节奏

- 快慢交替，至少一次明显加速或减速，至少留一次停顿给观众呼吸。
- 字幕停留时长约为“字数 ÷ 4.5 + 1.5 秒”，标题卡至少 2.5 秒。
- 设计一个标志性镜头：长镜头、尺度揭示或专属转场，让观众记住。

## 制作分工

- 真实运动、人物、环境用 generate_video；商品与品牌字用代码动效或 hybrid 叠加，保证可编辑与准确。
- 旁白先定稿再配音，字幕按真实语音对齐；配乐与旁白错开重音，旁白段落压低音乐。
- 每镜在 set_production_plan 里标明 generated / code / hybrid 与用途。

## 审片

export_video 后检查：主张是否在画面和旁白里都出现；标志性镜头是否成立；字幕是否遮挡主体；结尾品牌停留是否足够。只修有问题的镜头。
