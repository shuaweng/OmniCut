# 知识讲解短片

目标：观众看完能用一句话复述这个概念。产出：讲解脚本、图解分镜与成片。

## 脚本结构

1. 问题（0–5 秒）：一个观众关心、能被画出来的问题。
2. 直觉比喻：用一个熟悉的东西类比，先建立直觉。
3. 分步拆解：两到四步，每步一个画面状态的变化；每一步旁白不超过两句。
4. 总结：回到问题，一句话答案与一个记忆画面。

旁白语速约每秒 4–5 个字，30 秒约 130 字。

## 画面原则

- 画面跟着旁白逐步搭建：说到哪个元素，那个元素才出现；已讲过的内容降低不透明度保留在画面里。
- 一个画面只有一个焦点，用颜色或运动标出正在讲的部分。
- 用代码动效做图解（流程连接、线框空间、图表、字排），保证准确可改；需要真实场景时才用生成视频。

## 制作

先写脚本并用 generate_audio 配旁白，拿到真实语音时间后再排画面；字幕按语音对齐。每个步骤的画面变化对齐对应句子的起点。

## 自查

关掉声音只看画面，步骤是否仍然看得出顺序；只听声音，概念是否完整。
