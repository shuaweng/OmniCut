# MiniMax H3 提示词

目标：让每次 H3 生成都只表达一个清楚的镜头。产出：可直接作为 generate_video 提示词的结构化文本，以及本镜在影片中的用途。

## 先选模式

按手上的真实素材选模式，不为了“更强”而多塞参考：
- 文生音视频：只有文字设定，适合氛围镜头、空镜与概念画面。
- 首帧生成：已有一张确定的开场画面（商品图、定妆照），从这一帧往后演。
- 首尾帧：已有开头和结尾两张图，描述两者之间连续、合理的运动。
- 尾帧生成：只有结尾画面，倒推一个自然的起势落到这一帧。
- 多参考：需要同时保持人物、商品、场景或声音的一致性，用图片、视频、音频参考共同约束。

先 get_media_capabilities 确认本次允许的模式、时长与画幅；H3 单段 4–15 秒，剪辑时长可以短于生成时长。

## 三段式结构（基础模式）

1. 画面综合描述：构图与景别 → 主体是谁、在哪、做什么 → 环境与光线 → 镜头运动。按时间顺序写，一句一个动作。
2. 整体声景：画面内的声音（环境声、动作声、材质声），写具体来源，例如“瓷瓶盖轻叩木桌的短促闷响”，不写“好听的音效”。
3. 画外配乐：乐器、速度、情绪走向与结束方式；需要后期另配音乐时写“无配乐”，避免与工程音轨打架。

多参考模式扩展为六段：参考对象定义 → 一句话概要 → 每个参考需要保留的细节 → 分时段画面描述（写清哪个参考在哪个时刻出现）→ 整体声景 → 画外配乐。

## 镜头语言

每个镜头只给一种主运动，写三要素：类型（推、拉、摇、移、升降、环绕、跟拍、固定）、幅度（轻微 / 中等 / 大幅）、速度（缓慢 / 匀速 / 迅速）。例如“镜头缓慢向前推近约三分之一，停在瓶身标签”。避免同一镜头里推拉摇混用。

## 参考标签

图片、视频、音频分别编号为〈图1〉〈视频1〉〈音频1〉，在每个段落用同一个标签指代同一对象；每个标签都要在定义里说明它是什么，不留未定义标签。商品参考只说明需要保真的外形、颜色与文字，不臆造功效与包装细节。

## 对白与字幕

人物台词用说话人编号标注（说话人1、说话人2），台词保留原文；需要清晰可读的画面文字时写明内容、位置与出现时刻，品牌字与关键卖点更推荐后期用 OmniCut 字幕与代码动效叠加，保证可编辑。

## 常见失误

- 描述长度与目标时长不符：4 秒写了三个场景。
- 用“电影感”“高级”“唯美”代替具体的光线、材质与动作。
- 写剧情梗概而不是镜头里看得见的东西。
- 参考标签前后不一致，或没有说明参考的用途。

生成后用 preview_frames 检查真实画面再决定是否入片；不合格时只改出问题的那一项（构图、动作或参考），不要整段重写。
