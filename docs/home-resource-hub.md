# 首页创作与资源入口

左侧项目列表用于返回已有项目，保留右键修改名称。主区域始终保留原生创作输入框；下方项目、素材、动效、技能广场四个标签页只更换资源内容，不卸载输入框。

## 资源带入

- 项目：搜索项目、打开已有工作台。
- 素材：浏览全局素材与已有项目素材。项目来源只读；选用后，在新项目创建时通过原有 library-publish / library-use 接口复制或挂载，不修改源项目。
- 动效：浏览原生预览、选择完整场景或片段；将 componentId、改稿参数和源区间带入真实用户指令，Agent 先 get_motion_component 读接口，再 use_motion_component 获取可编辑源码并接入影片。
- 技能广场：浏览内置/导入技能。新任务选择导入技能后，创建项目时使用已有技能启用接口；不可启用的技能不提供选用。它是本地技能目录，没有虚构线上社区数据。

用户选中的资源显示在输入框下方，可逐项移除。标签页、资源预览、右键菜单支持键盘操作。图标沿用 Lucide，输入与附件沿用原生组件。

## 本轮验收修复

本机 API、Studio 与 Agent 服务使用一次性本机配对与 HttpOnly cookie；npm run open 和本机启动器完成浏览器连接，重启保留连接。配置接口不再返回 .env 路径。

模型选择在真实用户输入与制作面板保存处记录，生成工具执行时核对 provider/model/quality。模型自称“已确认”不算用户改选；明确选择沿用后续轮，面板的新选择覆盖旧对话选择。参考批量生成也传递模型名称。未明确指定清晰度时可降级到模型支持的较低规格，不能自行升级。

坏对话记录保留原文件并隔离恢复。成片卡展示实际时长、画幅和文件大小，可直接保存、预填后续修改；历史成片也可保存。失败卡显示可执行处理入口，原始错误折叠。素材删除先显示实际使用情况，仍有引用的素材不能直接删除。停止助手后仍在处理的任务继续列出，不声称远端已取消。

保留已核实的原生能力：预览内层 opaque sandbox、同项目视频变体、作者百分比转换、工具与媒体持久化。没有为误报另写替代实现。
