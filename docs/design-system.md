# OmniCut 界面约定

界面共用 `src/design-system.css`。首页、设置页、原生聊天与视频工作台都加载同一份变量，不为单个页面追加新的灰色、字号或圆角。

| 用途 | 变量 / 数值 |
| --- | --- |
| 页面、面板、浮层 | `--oc-bg-page`、`--oc-bg-panel`、`--oc-bg-elevated` |
| 主文字、次要文字、弱提示 | `--oc-text-primary`、`--oc-text-secondary`、`--oc-text-muted` |
| 描边 | `--oc-border` |
| 主操作 | `--oc-accent` |
| 字号 | 12 / 13 / 15 / 20px |
| 字重 | 400 / 600 |
| 控件、卡片、弹窗圆角 | 6 / 10 / 16px |

橙色用于当前界面的主要动作：首页开始创作、工作台导出、设置页保存。选中态、播放头、标签线、上传及次要按钮保持中性。首页输入卡片仅聚焦时使用橙色描边；图片、视频内容和服务商原有 Logo 不做界面颜色归一化。

资源工具栏依次放搜索、类型选择、可选的更多筛选，操作放在最右边。音频用带时长和试听的列表，其余素材用缩略图卡片。无封面的项目只展示统一占位图，名称写在卡片下方。

工作区左侧对话、右侧剪辑，中间保留可调整的分隔条。项目顶栏主要提供视频切换、画幅和导出；辅助操作在「更多项目操作」中。时间线只保留一处完整时间码，片段名称与时长在悬停或选中时显示；轨道折叠后保留素材块。字幕使用细条，并保留足够的点击区域。

原生聊天只改变颜色、密度和插件扩展，不替换会话组件。主会话使用外层标题与目标视频副标题；子代理使用原生层级与返回导航。输入区保留附件、当前制作配置、模型和发送，素材库、参考视频、动效库收在附件菜单。

模型设置按能力分组，右侧统一使用内嵌字段；连接设置进入对应服务商。API Key 的掩码、空值保护和差异保存逻辑保持独立于外观。
