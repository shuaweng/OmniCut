# OmniCut 0.2.0

这次把最近在本地使用、调整的版本同步到公开仓库，也把首页置顶作品留下来：不止能看 MP4，还能导入工程，看看画面、声音和动效是怎么编排的，再接着改。

## 带进来的内容

- 更新后的首页、聊天与工作台，项目置顶，以及扩充的动效画廊和技能广场。
- 内置 Agent 与视频内核的最新本地改动，安装不依赖同级目录中的上游仓库。
- 五个置顶项目、六个视频版本：两版 61 秒 OmniCut 宣传片、雅诗兰黛 30 秒与 15 秒广告、大宝 SOD 蜜 30 秒广告、OmniCut 数字人口播短片。
- 对应的可编辑工程、实际引用的图片和音视频素材、字幕时序、组件源码、字体与许可。原版 OmniCut 宣传片已按最新工程重新本地导出。
- 更新的产品截图、六条可播放样片及模型配置说明。

## 本地体验

准备 Node.js 24+ 和 FFmpeg，进入仓库目录：

```sh
npm run setup -- --prepare-browser
npm run examples:import
npm start
```

另开终端运行 `npm run open`。首页会出现五个置顶工程，其中宣传片项目包含两个视频版本。查看成片和本地编辑不需要调用生成模型；对话与重新生成素材需要填写自己的服务配置。

示例导入默认拒绝覆盖已有同名项目或成片。已有安装可先运行 `npm run examples:verify` 检查素材包，具体内容见 [示例说明](../examples/README.md)。

## 本轮验证

全量本地隔离测试为 333 项：332 通过、0 失败、1 项按原配置跳过。六个示例工程通过原生编译检查，130 条原生相对资源引用完整。六条成片都有音轨，且对应当前打包工程的版本；新版宣传片完成 1830/1830 帧本地渲染。

素材包保留的是公开展示需要的内容，未携带密钥、对话历史、供应商请求日志和本机绝对路径。仍然是个人概念作品与本地 Alpha，没有商业投放效果数据。
