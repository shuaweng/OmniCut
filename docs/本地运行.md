# 在自己的电脑上运行 OmniCut

这是一个单仓库安装的本地视频创作工作台，对话、编辑与渲染内核都已随源码内置。网页、项目文件和剪辑工程在自己电脑上运行；对话、生图、生视频、配音等能力按你选择的模型服务计费。仓库不包含作者的 API Key，也不包含完整的制作历史。

目前按 macOS / Linux 准备安装流程。Windows 可以使用 WSL，原生 Windows 尚未验证。

## 先准备这些

| 依赖 | 用途 |
| --- | --- |
| Node.js 24 或更新版本，含 npm | 运行产品和 Agent |
| Git（或下载仓库 ZIP） | 获取 OmniCut 源码 |
| FFmpeg / ffprobe | 导入素材、检查音视频、抽帧和合成 |
| 可以访问 npm 和 Chrome for Testing 的网络 | 首次安装通用依赖和渲染浏览器 |

在 macOS 上，如果已安装 Homebrew，可以用 `brew install node ffmpeg git` 准备常用依赖。无论采用哪种安装方式，都先运行 `node --version`，确认版本至少为 24。

## 安装和启动

选一个可以存放项目的父目录，再运行：

```sh
git clone https://github.com/shuaweng/OmniCut.git
cd OmniCut
npm run setup -- --prepare-browser
npm start
```

在另一个终端运行 `npm run open`，浏览器会自动连接 [本机工作台](http://localhost:5180)。进入「模型设置」填写自己的服务信息。首次保存时会创建本地 `.env`，不需要提前复制或修改模板。

所有内核都在当前仓库，不需要额外克隆项目、安装全局 DSH，或另外摆放 Hypit 目录：

```text
OmniCut/
├── engines/agent/source/   对话内核的原始源码与构建工具
├── engines/agent/runtime/ 同版本、可直接运行的内置包
├── engines/video/         视频工程、Studio、渲染与创作 Skills
├── harness/               OmniCut 创作工具和交互扩展
└── server/                统一项目、素材与任务服务
```

`npm run setup` 统一安装产品、对话和视频内核所需的 npm 依赖。对话运行包由本仓库的 workspace 链接，视频内核使用仓库内固定的 lockfile；不再从上游拉取另一份工程。普通第三方库与对应平台的二进制依赖仍通过包管理器下载。

无需在各内核目录分别执行安装步骤。`engines/` 中保留来源、许可证与构建说明，开发者可以继续修改和维护内核；内化并不改变上游许可证。

`--prepare-browser` 会显式准备视频渲染所需的 Chrome Headless Shell，默认缓存位于 `~/.cache/hyperframes/chrome`。这一步可能需要下载较大的浏览器文件，不会请求付费模型。以后启动产品只需 `npm start`，无需每次重新安装。

如果想先安装依赖、稍后下载渲染浏览器，可以分开执行：

```sh
npm run setup
node scripts/hypit.mjs programs prepare --runtime template/hypit.runtime.json --endpoint hyperframes.local
```

只检查安装条件，不下载、不启动服务：

```sh
npm run setup -- --check
```

## 模型怎么配

不必把每个服务都填一遍。在「创作配置」先选择任务执行模型，再为自己需要的图片、视频和声音能力各选一个服务；**填好 Key 后，还要选中该能力使用的服务**。

下表描述当前代码里已有的接口，不承诺所有账户都已开通对应模型。模型 ID、地域和接口权限，以你自己的服务账户为准。

| 能力 | 当前接入 | 要填什么 | 什么时候需要 |
| --- | --- | --- | --- |
| 主 Agent：理解指令、调用工具、剪辑与修改 | 通用对话接口（DeepSeek），或 Claude 的 Anthropic Messages 接口 | API Key、模型 ID、接口地址；Claude 可沿用「创意与理解」的连接，或填写独立连接 | 用对话操作产品时；主力模型与创意模型可以分别选择 |
| 创意导演：脚本、分镜与创意评审 | Anthropic Messages 或 OpenAI Chat Completions 兼容接口 | 自己选择的 HTTPS 接口地址、API Key、模型 ID、正确的协议 | 写创意 / 分镜、评审方案；可在「创作配置」暂停独立创意模型 |
| 参考理解与成片审片 | 当前创意模型，或 Gemini | 创意模型使用已有连接；Gemini 填接口地址、Key、模型 ID，选择标准或流式接口 | 拆解参考片与检查成片；两种用途可以分别选服务，审片也可以沿用参考理解服务 |
| 图片 | 快跑、Musk API、RunningHub、火山方舟 | 对应服务的 Key 和界面支持的模型：快跑 GPT Image 2.5（1K / 2K / 4K）、Musk GPT Image 2.5 Sunburst、RunningHub Seedream 5 Pro；火山方舟可填写自己的 Seedream 模型 ID | 生成商品图、人物图、关键帧，或使用参考图编辑 |
| 视频 | 火山方舟 Seedance、MiniMax、RunningHub | 对应服务的 Key、模型；MiniMax 另选地区 | 生成镜头；仅导入现有素材时不需要 |
| 配音 | ElevenLabs、MiniMax、小米 MiMo | 对应服务的 Key、模型和音色 | 生成独立旁白 |
| 配乐 | ElevenLabs、MiniMax | 对应服务的 Key 和音乐模型 | 生成背景音乐；需账户有相应接口权限 |
| 音效 | ElevenLabs | Key 及音效权限 | 生成环境声、转场或强调音效 |
| 语音识别与时序 | ElevenLabs Scribe，或本地 WhisperX | 云端使用 ElevenLabs Key；本地使用已准备好的 WhisperX 环境 | 导入音频的识别与字幕对齐；已有配音时序时可直接复用 |
| 远端执行扩展 | 设置中的「扩展服务」 | 仅需要该扩展时填写它的 Key | 可选；使用上述独立模型服务不需要额外购买视频内核网关 Key |

主 Agent 和创意模型的接口地址都可以自行填写，不要求使用作者曾经试用过的第三方网关。Claude 主力模型的默认预算为 384K 上下文、32K 单次输出，可以在「任务执行」的「思考与用量」中调整；这只是产品请求参数，实际模型和服务商仍需支持对应预算。主力模型可选择 Sonnet、Opus 或服务商支持的其他 Claude 模型 ID。

兼容协议只是接入前提，模型名、图像输入、输出长度和额度也要由所选服务实际支持。主 Agent 的连接承担工具执行；「创意与理解」承担创意子代理与所选择的理解任务，两者不是必须使用同一个模型。

使用创意模型理解参考视频时，产品提供抽帧、时间点和可用的语音证据，要求模型与网关支持图像输入；Gemini 路径可提交含音轨的视频，并支持独立音频和截帧证据。不要把它理解为所有模型都可以原生读取整个 MP4。参考片段的长短、动作细节和音乐节奏，仍需要看实际分析结果。

设置保存在本机 `.env`，密码框留空会保留已有 Key。保存设置本身不执行生成任务，也不等于服务已经鉴权成功。浏览器不会收到已保存的完整 Key；提交任务时，后端会将需要的指令、参考素材发送给你选择的服务。

如果习惯手动配置，可对照 [`.env.example`](../.env.example)。不要把 `.env` 提交到 Git。修改环境变量后重启产品；在页面保存支持的模型配置，会重新加载相关 Agent 配置。

## 本地处理能力按需安装

普通启动不要求安装全部 Python 工具。

- 图像裁切、合成等 OpenCV 能力：先安装 [uv](https://docs.astral.sh/uv/getting-started/installation/)，再在项目根目录运行 `sh setup-media.sh`。脚本使用 Python 3.12，环境放在 `.opencv-python/`。
- WhisperX：它是可选的本地语音识别 / 对齐服务，需要额外下载模型和准备 Python 环境。启用前先在模型设置中选择本地识别，再让 Agent 准备对应端点。CPU 模式可能明显慢于云端，首次模型下载也可能较久。
- Chrome 渲染浏览器：由上面的 `programs prepare` 准备，和日常使用的 Chrome 标签页是两回事。

## 常见卡点

| 现象 | 先检查什么 |
| --- | --- |
| 升级后提示旧版外置对话包或缺少内核依赖 | 在 OmniCut 根目录重新执行 `npm run setup`；不会覆盖模型设置或项目 |
| 页面打不开 / 端口占用 | 确认 `npm start` 的终端仍在运行；默认产品端口为 5180，内部对话端口为 5182；另开实例时分别设置 `PORT` 和 `OMNICUT_AGENT_PORT`，且使用独立的项目目录 |
| 界面正常，导出提示找不到浏览器 | 执行上面的 `programs prepare`；已有工程若显式配置了其他缓存或 `chromePath`，也要保证对应文件存在 |
| 图片、视频等提示未配置 | 除了保存服务商 Key，还需选中该能力的默认服务 |
| 服务返回 401 / 403 / 模型不存在 | 核对 Key、项目 / 分组权限、服务地区、模型 ID 和额度；不要靠反复提交生成任务排查 |
| 本地字体、图片或音频找不到 | 不要只搬一个工程源码文件，素材目录也需一起保留 |

当前服务只监听 `127.0.0.1`，用于自己的电脑。它不是已经完成账号隔离、多人权限和在线部署的 SaaS。

项目、素材、任务记录与视频内核运行状态保存在 `data/`，不随源码上传。本地工具缓存保存在 `.cache/` 或服务默认的用户缓存目录。换电脑时，先停止正在执行的任务，再单独备份项目数据和自己需要保留的设置。不要把凭据备份公开上传。
