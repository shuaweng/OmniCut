Frame 大宝参考广告体验修复 · 2026-10-08

本轮范围
根据实际完成的 30 秒大宝 SOD 蜜广告体验记录优化工作台、交付入口和制作衔接。
保存 Frame 应用的首个本地 Git 快照，不包含密钥、会话、用户原片及生成产物，不推送远端。
本机运行仍依赖相邻 Hypit checkout 和已安装的媒体环境，Git 快照不是全部运行数据的备份。
依赖：Hypit checkout 1f8f4e1b8a00ecf8e5680233dfc6584e736a0eea；实际 DSH npm 0.2.0-rc.2（package-lock 锁定）。

已实施
1. 完整工作台的预览与对话连接
   原生聊天覆盖了旧聊天，但旧节点中的九个视频仍会加载；现在直接卸载旧节点。
   聊天里的历史媒体采用封面，点击时才打开播放器；关闭播放器释放媒体请求。
   工作台进度改为有超时的短请求，后台标签暂停；原生聊天流仍由 DSH 承担。
   老版 EventSource 限定连接寿命并延迟重连，避免旧标签永久占用 HTTP/1 连接。
   Frame 产品配置关闭 DSH 的开发热更新通道 client-hmr（/plugins/events）；原生启动模块、会话和工具流不变。代码更新需刷新页面，避免每个项目额外常驻一条 SSE。
   进度接口不重复传输完整聊天记录，保留原生聊天独立的会话流。
   DSH 扩展使用原生 effect 生命周期卸载订阅，阻止失效上下文的延迟回调。
   WebSocket 握手返回 401 等非升级响应时及时结束连接，补齐代理超时，避免重启后凭证过期占满连接。
   进度检测到会话服务更换后刷新本机会话凭证，由 DSH 原生连接恢复；保留对话 iframe 与未发送草稿。
   原生 Studio 在服务重启后使用新的场景版本。保留上游播放器、时钟和时间线逻辑。
   本地媒体正确返回 Range、HEAD 和内容长度，关闭响应时取消文件流。
   修复转发层丢失 x-hypit-storyboard-* 响应头：上游组件因此无法读取缩略图图集，提前退出并留下未消费响应，造成多标签 HTTP 连接堵塞。
   现在保留原生图集尺寸、帧数与采样参数及缓存策略，时间线出现真实镜头缩略图；无需改写播放器。
   排查中尝试的媒体分块与后台卸载预览均未解决根因，已撤销，未混入最终实现。

2. 用户看得到的提交与交付
   输入框反馈“正在发送 / 已接收”，来源是 DSH 的真实提交状态；不把发送按钮清空当成功。
   停止操作立即反馈请求状态，但不宣称已经取消远端媒体任务。
   点击“成片已导出”直接打开本版成片。成片列表突出最新版本，旧版本折叠。
   请求超时允许重试读取；写入超时显示结果尚未确认，不自动重复生成。
   已有替代素材或更晚成片的历史失败进入历史；新的失败、仍运行及仍等待的任务保留。

3. 参考分析与素材
   火山欠费、用户 401、供应商 502 内部认证问题区分归因，不统一要求换 Key。
   新增 recover_reference_plan：实际查看关键帧后，可将分析写回同一 referenceId 与 productionPlan。
   要求每段有实际查看时间点；从原片提取方案缩略图，保存恢复来源和原失败记录。
   未核实音轨时明确标注，不把关键帧观察伪装为完整视频/声音理解。恢复本身不生成素材。
   首页面上传参考片后，入口标签跟随参考改编。
   质检抽帧和拼图不再默认挤进素材库，文件保留；已被工程实际使用的素材仍可访问。
   常见轨道、默认镜头、语义旁白与尾板中文化，仅变更显示名，不改源码 ID。

4. 制作质量约束
   prepare_hypit_speech 新增实际发声和静默区间，排除标点跨越的长停顿；保留原始测量证据。
   技能要求把这些区间随 Take 取段、位移映射到字幕留白，不能仅凭字级对齐声称节奏正确。
   旁白按镜头语义分布、品牌句落尾板；人物发型、衣服、商品开盖结构需逐镜对照参考。
   唯美广告默认轻量白字，不套实心灰底；尾板注意真实商品图底色，不反复生成微弱可选音效。
   独立前置任务完成即接续，不让一个已完成首帧等待无关慢视频；工作区检查媒体不发布为创作素材。

实际验证
隔离的定向用例通过：进度/历史、参考恢复及缩略图、语音留白、素材可访问性、错误归因、读取超时、中文显示；原生编辑→源码保存→撤销与版本更新。
Studio 用例最初因沙箱不允许监听本机端口失败，在允许本机监听的隔离临时工程重新执行通过。
Chrome 完整工作台已观察到商品画面、音频波形及原生播放至尾板；点击成片入口可播放导出 MP4。
最后针对复现过的多标签堵塞，两个全新项目标签同时打开、前台刷新、选择镜头和播放均成功；真实镜头缩略图与声音波形可见。
隔离 Studio 用例新增真实上游 PNG 图集经过 Frame 响应适配后的协议验证，连同原生手改、源码保存与撤销通过。
用“不调用工具、不修改项目”的极短真实对话验证发送，已看到“已接收”和实际回复。
本轮没有重新生成付费图像/视频/声音，不把规则更新当作新片质量已得到证明。

尚未解决或需继续体验的点
- 上传素材路径与代码工作区首次读取仍依赖 stage_asset / 原生 read，尚未统一文件读取状态。
- 自由编写空工程仍可能漏 appearance / Track 等语法前置条件；应继续完善可直接创作的合法骨架。
- 部分底层工具名、技能名和源码路径仍在原生轨迹里露出，展示层尚未全部中文化。
- “已接收”仅证明进入会话，不等于当前修订已被执行；远端已提交生成不能立即撤销。
- 角色一致性、音乐衔接、包装小字和新字幕规则仍需下一条实际广告审片，尤其需要真实听音。
- 本次复现的双标签连接堵塞已修复；长时间运行、更多标签及网络频繁切换尚未做长期验证。
