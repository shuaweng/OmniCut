本轮交互与视觉整改

设计基础
- 统一入口 src/design-system.css。根页面、原生聊天和视频工作台共享背景、文字、描边、字号、字重和圆角。
- style.css 和 model-settings.css 均不再含颜色字面量；字号使用 12/13/15/20 四档，字重使用 400/600。
- 主操作保留橙色；品牌界面标志、播放头、选中状态、标签线与次要操作使用中性颜色。媒体内容与服务商 Logo 保留本色。

页面变化
- 首页输入卡片与资源区使用同一栅格；项目占位封面去重名称。
- 素材、动效和技能共用搜索、类型、操作的工具栏顺序。音频改为左对齐横条，显示时长并直接试听。
- 聊天在左、剪辑工作台在右。中间分隔条支持鼠标拖动和键盘调整；保留宽度记忆。
- 顶栏突出导出，其余项目操作收进菜单，制作进度用数字徽标。撤销放到时间线工具栏。
- 时间线只保留一处完整时间码，低饱和素材块默认不压名称和时长，悬停或选中再显示；字幕为细条，折叠轨道保留素材块。
- 聊天主会话标题只显示一次，目标视频放副标题；原生聊天头压成 38px，保留子代理目录和侧栏开关。生成图片使用两列缩略图。
- 输入区只保留附件、当前制作配置、模型和发送；素材库、参考视频、动效库在附件菜单。
- 模型设置按能力分组，右侧统一内嵌字段，连接设置跳转至对应服务商。

实际界面验收
- 首页输入区与资源区测得 x/width 完全相同。
- 首页发送启用后为橙底深色文字；平时输入框为中性描边。
- 素材类型选择器使用 base-select；再次点击后 :open 从 true 变为 false。
- 音频能进入试听/暂停状态；类型、动效分类与技能导入弹窗正常。
- 模型设置各能力字段可读取，参考理解连接设置进入已选择的创意服务商；未改保存配置或读取密钥。
- 工作区宽度键盘调整生效；参考改编覆盖层从工作台左边缘开始，聊天保持可见。
- 更多操作点击两次展开/收起；素材库、参考改编、本次制作入口可打开。
- 工作台播放与时间码推进正常；轨道折叠为素材块；画面右键显示引用这一刻/画面/声音/字幕菜单。
- 子代理目录点击后可查看完整记录、返回主会话，原生侧栏也可展开并返回。
- 代码项目与真实视频项目均加载并查看。纯 VM 导航检查及源样式解析通过。

验收中补修
- 参考改编沿用旧右侧聊天定位，会盖住新左侧聊天。
- 原生会话槽的替换方案触发回退，改为会话列表订阅与 CSS 适配，不替换原生组件。
- 精简聊天头时隐藏了原生子代理与侧栏按钮，按其真实 DOM 位置重新排成一行，已验证可点击。
- 禁用按钮和通知文字对比不足、参考分析转圈无明暗区别、审片卡片悬停无反馈、音频行名称意外居中。

范围
- 本轮没有生成新媒体或调用付费模型，没有修改视频工程。
- 鼠标拖动的流畅性依据现有 pointer capture / requestAnimationFrame 实现检查；浏览器实际验证了键盘调整，未进行鼠标连续拖动性能测量。
- 当前以桌面界面验收；移动端堆叠布局做了源码定位修正，未完成触屏设备验收。
- 截图在 research/ui-design-system-2026-10-11/。既有推理等级变更和上一轮宣传片记录不属于本轮提交。
